# Beschreibung

Eine ehemalige US-amerikanische Filmproduktionsgesellschaft, die 1987 von Rob Reiner und vier weiteren Filmproduzenten gegründet wurde. Das ehemalige Unternehmen ist heute als Abteilung von Warner Bros. (Quelle: Wikipedia)
